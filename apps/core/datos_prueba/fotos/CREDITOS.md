# Fotos de los datos de prueba

Fotos de Wikimedia Commons con licencia libre, para cargar datos de prueba realistas
(`manage.py cargar_datos_prueba`). Ninguna es de un animal de Ushuaia: los nombres, las
historias y los lugares de los datos de prueba son inventados.

Cambios: cada foto se redujo a 640 px de lado mayor y se le quitaron los metadatos. Las fotos
con licencia CC BY-SA se comparten con la misma licencia.
